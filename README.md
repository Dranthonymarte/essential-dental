# Essential Dental — web de la marca

Página oficial de **Essential Dental**, el software para odontólogos (historia clínica con odontodiagrama, presupuestos, cobros en $ y Bs, agenda en línea y récipes).

- En línea: https://dranthonymarte.github.io/essential-dental/ (dominio futuro: essentialdental.app)
- La app: https://clinica-dental-app.pages.dev (futuro: mi.essentialdental.app)
- Sitio estático de una página: `index.html` (estilos y script en línea), imágenes en `img/` (WebP), `og.png` para compartir.
- Las capturas salen de la app con la clínica de prueba (`scripts/capturas.cjs` en el repo de la app); nunca con pacientes reales.
